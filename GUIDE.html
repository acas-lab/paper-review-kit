1프로그램 소개

논문 PDF 한 편을 넣으면, 공부용으로 만들어진 웹페이지 한 장(HTML)이 나옵니다.

이게 무슨 프로그램인가요

영어 논문을 읽을 때 필요한 것들 — 문장별 번역, 그림·표 해설, 논문 구조 분해, 배경지식, 수식 정리, 비판적 질문 — 을 탭 8개짜리 학습 페이지 하나로 정리해 줍니다. 특정 분야(AI/ML)에 묶이지 않습니다 — 자연과학·공학·AI/CS·의학·인문사회 어느 분야의 논문이든 같은 절차로 만듭니다.

버튼 하나로 끝나는 자동 변환기가 아닙니다. AI(Claude)와 채팅으로 대화하면서 단계별로 만들어 나가는 방식입니다. 그래서 중간에 이 번역 어색해 이 그림 다시 같은 요청을 넣어 고칠 수 있습니다.

결과물의 장점 그림·표가 파일 안에 전부 들어간 단일 HTML 파일입니다. USB에 담거나 메일로 보내도, 인터넷이 없어도, 다른 컴퓨터에서 더블클릭만 하면 그대로 열립니다.

이 안내서를 읽는 법 — 용어 3개

이 세 단어만 알면 아래 모든 단계를 따라 할 수 있습니다.

용어뜻
터미널 글자만 있는 검은 창입니다. 여는 법: 키보드에서 Win+R → cmd 입력 → Enter. 또는 시작 메뉴에서 “명령 프롬프트”를 검색해 실행합니다. 이 안내서에서 “터미널에 붙여넣기”라고 하면 이 창을 말합니다.
붙여넣기 이 안내서의 회색 상자 오른쪽 위 「복사」 버튼을 누르면 내용이 복사됩니다. 터미널에서는 Ctrl+V 또는 마우스 오른쪽 클릭으로 붙여넣습니다. 그다음 Enter를 누르면 실행됩니다.
킷 폴더 내려받은 압축을 푼 paper-review-kit 폴더입니다. 안에 setup, webapp, rawpaper, papers 폴더가 있습니다. 경로에 한글·공백이 있어도 되지만, 터미널에 경로를 쓸 때는 큰따옴표로 감쌉니다 — 예: cd "C:\Users\홍길동\Desktop\paper-review-kit".

완성되는 8개 탭

탭내용
Translation영어 원문 ↔ 한국어 번역을 문장 단위로 나란히. 마우스를 올리면 짝이 되는 문장이 같이 강조되고, 그림·표에 해석과 초보자 해설이 붙습니다.
Paper Study비판적 읽기 워크북. AI 해설을 보기 전에 내 생각을 먼저 적고, 그다음 AI 분석과 비교합니다.
Paper Dissection연구 동기 · 핵심 관찰 · 차별점 · 방법 · 실험 검증 · 한계 + 논문 총정리 카드.
Background이 논문을 읽기 전에 알아야 할 배경지식 카드.
Mathematics핵심 수식 풀이.
Diagrams비판적 질문 + 이해를 돕는 도식.
Code알고리즘 시뮬레이터 (기본은 빈 껍데기 — 필요할 때만 따로 요청)
Q & A자가 점검 문답 (기본은 빈 껍데기 — 공부하다 남긴 메모로 채울 수 있음)

두 가지 사용 방법 — 하나만 고르면 됩니다

방법 A · 추천
웹앱으로 하기
파일 하나를 더블클릭하면 브라우저 화면이 뜹니다. PDF를 끌어다 놓고 채팅창에서 대화합니다. 검은 터미널 창을 직접 다룰 일이 거의 없습니다.
방법 B
Claude Code(터미널)로 하기
터미널에서 claude를 실행해 직접 대화합니다. 조금 더 빠르고 세밀하게 조정할 수 있습니다. 문장 몇 개를 복사·붙여넣기만 하면 됩니다.

두 방법 모두 결과물은 같습니다. 그리고 두 방법 모두 아래 「2. 처음 한 번 준비」가 먼저 끝나 있어야 합니다.

2처음 한 번 준비 (Windows)

컴퓨터 한 대에 한 번만 하면 됩니다. 위에서 아래로, 한 단계씩, 앞 단계가 [OK]로 끝난 뒤에 다음 단계로 갑니다.

setup 폴더의 실행 파일에 대해 킷 폴더 안 setup 폴더에 0_check.bat 부터 7_install_codex_optional.bat 까지 8개의 실행 파일이 있습니다. 각 파일은 더블클릭하면 검은 창이 열리고 영문 메시지로 진행됩니다. 끝나면 마지막 줄에 [OK] 또는 [FAIL]이 찍히고 Press any key to continue . . . 에서 멈춥니다. 이 마지막 줄만 확인하고 아무 키나 눌러 창을 닫으면 됩니다. [FAIL]이면 그 위에 적힌 영문 안내를 읽거나, 각 단계의 「안 되면」 항목을 따릅니다.
  1. 킷 내려받기
    목표
    내 컴퓨터에 paper-review-kit 폴더를 만듭니다. git 같은 프로그램은 필요 없습니다.
    할 일
    1. 브라우저에서 https://github.com/acas-lab/paper-review-kit 을 엽니다.
    2. 초록색 「Code」 버튼 → 「Download ZIP」 을 누릅니다.
    3. 내려받은 paper-review-kit-main.zip 을 마우스 오른쪽 클릭 → 「압축 풀기」. 바탕화면이나 C:\ 아래 등 기억하기 쉬운 곳에 둡니다.
    4. 압축이 풀린 폴더 이름이 paper-review-kit-main이면 그대로 두어도 됩니다. 이 안내서에서는 이 폴더를 킷 폴더라고 부릅니다.

    git을 쓸 줄 안다면 터미널에서 아래 한 줄로 받아도 됩니다.

    git clone https://github.com/acas-lab/paper-review-kit.git
    확인
    킷 폴더를 열었을 때 setup, webapp, rawpaper, GUIDE.html이 보이면 성공입니다.
    안 되면
    ZIP 파일을 더블클릭해 안을 들여다본 상태에서는 실행 파일이 동작하지 않습니다. 반드시 「압축 풀기」를 먼저 하세요.
  2. 현재 상태 확인 — setup\0_check.bat
    목표
    무엇이 이미 설치돼 있고 무엇이 없는지 봅니다. 아무것도 설치하지 않습니다.
    할 일
    킷 폴더 → setup 폴더 → 0_check.bat 을 더블클릭합니다.
    확인
    검은 창에 항목별로 [ OK ] / [ NO ] 이 나열되고, 마지막 줄이 이렇게 끝납니다. 
    [ NO ] python      : not found  --> run 1_install_python.bat
[ NO ] node        : not found  --> run 2_install_node_and_claude.bat
[ NO ] claude      : not found  --> run 2_install_node_and_claude.bat
[ -- ] codex       : not found  (OPTIONAL - 7_install_codex_optional.bat)
------------------------------------------------------------------
[TODO] Steps still to run, in this order: 1 2 3 4
       (double-click  N_*.bat  for each number above, one at a time)
------------------------------------------------------------------
Press any key to continue . . .
    처음이면 대부분 [ NO ]입니다. 정상입니다. 아무 키나 눌러 닫고, [TODO] 줄에 적힌 번호 순서대로 아래 단계를 진행합니다. 마지막 줄이 [OK] Everything required is installed. 라면 2~5단계를 건너뛰고 준비 완료 체크리스트로 갑니다. [ -- ] codex 는 선택 항목이므로 없어도 됩니다.
    안 되면
    창이 열리자마자 닫히면 6장 「실행 파일 창이 바로 닫힘」. 한글이 깨져 보이면 6장 「한글 깨짐」.
  3. Python 설치 — setup\1_install_python.bat
    목표
    Python 3.12 를 설치합니다. PDF에서 글자·그림을 뽑는 데 씁니다.
    할 일
    setup\1_install_python.bat 을 더블클릭합니다. 설치 창이 뜨면 기다립니다(1~3분). Windows가 “이 앱이 디바이스를 변경하도록 허용하시겠습니까?”라고 물으면 「예」.
    확인
    [OK] Python installed: Python 3.12.x
Press any key to continue . . .
    창을 닫고, 새 터미널(Win+R → cmd)을 열어 아래를 붙여넣고 Enter. 
    python --version
    Python 3.12.x 처럼 버전이 나오면 성공입니다.
    안 되면
    'python'은(는) 내부 또는 외부 명령... → 6장. winget 을 찾을 수 없다고 나오면 → 6장. 설치 파일이 아예 안 받아지면 실행 파일이 안내하는 python.org 에서 직접 내려받아 설치하되, 설치 화면 맨 아래 “Add python.exe to PATH” 를 반드시 체크합니다.
    수동으로 할 때 (터미널에 붙여넣기)

    1) 설치 — 한 줄 전체를 복사해 터미널에 붙여넣고 Enter.

    winget install -e --id Python.Python.3.12 --override "/passive InstallAllUsers=0 PrependPath=1 Include_pip=1"

    2) 확인 — 터미널을 닫고 새로 연 뒤 아래를 실행.

    python --version
  4. Node.js + Claude Code 설치 — setup\2_install_node_and_claude.bat
    목표
    이 킷의 엔진인 Claude Code를 설치합니다. Claude Code는 Node.js 위에서 돌기 때문에 Node.js 를 먼저 깝니다.
    할 일
    1. setup\2_install_node_and_claude.bat 을 더블클릭합니다.
    2. Node.js 가 방금 새로 설치된 경우, 창에 “close this window and run this file again” 안내가 나옵니다. 그러면 창을 닫고 같은 파일을 한 번 더 더블클릭합니다. (새 프로그램은 새 창에서만 인식되기 때문입니다.)
    3. 두 번째 실행에서 Claude Code 설치(npm 단계)가 진행됩니다. 1~2분 걸립니다.
    확인
    (첫 번째 실행 — Node.js 를 방금 깐 경우)
[OK] Node.js is installed, but this window cannot see it yet.
     CLOSE this window, then double-click THIS SAME file
     (2_install_node_and_claude.bat) once more to install Claude Code.
Press any key to continue . . .

(두 번째 실행)
[OK] Claude Code installed: 2.x.x (Claude Code)
Press any key to continue . . .
    새 터미널을 열어 아래를 붙여넣고 Enter. 버전 번호(예: 2.x.x (Claude Code))가 나오면 성공입니다. 
    claude --version
    안 되면
    'npm'은(는) 내부 또는 외부 명령... → 창을 닫고 같은 파일을 한 번 더 실행 (6장). npm.ps1 cannot be loaded 같은 빨간 글자 → 6장 「PowerShell 실행 정책」.
    수동으로 할 때 (터미널에 붙여넣기)

    1) Node.js 설치

    winget install -e --id OpenJS.NodeJS.LTS

    2) 터미널을 닫고 새로 연 뒤 Claude Code 설치

    npm install -g @anthropic-ai/claude-code

    3) 확인

    claude --version
  5. Claude 로그인 — setup\3_login_claude.bat
    목표
    Claude Code 를 내 Claude 계정(Pro/Max 구독)에 연결합니다. 한 번만 하면 이후에는 묻지 않습니다.
    할 일
    1. setup\3_login_claude.bat 을 더블클릭합니다. 검은 창에서 claude가 실행됩니다.
    2. 테마(색상)나 “이 폴더를 신뢰합니까?” 질문이 먼저 나오면 그냥 Enter. 로그인 방식을 고르라고 나오면 화살표 키로 “Claude account with subscription”(구독 계정)을 고르고 Enter.
    3. 브라우저가 열립니다. 내 Claude 계정으로 로그인하고 「Authorize」(허용)를 누릅니다. 브라우저에 “로그인 완료” 화면이 나오면 터미널로 돌아옵니다.
    4. 터미널에 > 로 시작하는 입력 칸(프롬프트)이 보이면 로그인이 된 것입니다. 아래를 입력하고 Enter 하여 나옵니다.
    /exit
    확인
    [OK] Logged in - credentials file found.
Press any key to continue . . .
    창이 이렇게 끝나면 성공입니다. (탐색기 주소창에 %USERPROFILE%\.claude 를 넣어 열었을 때 .credentials.json 파일이 있으면 로그인된 상태입니다.)
    안 되면
    브라우저가 안 열리면 터미널에 적힌 긴 주소(https://…)를 복사해 브라우저에 직접 붙여넣습니다. 로그인해도 [FAIL]이면 6장 「claude 로그인 안 됨」. “API key” 관련 경고가 보이면 6장 「ANTHROPIC_API_KEY 경고」.
    수동으로 할 때 (터미널에 붙여넣기)

    1) 실행 → 브라우저 로그인

    claude

    2) 프롬프트가 보이면 나오기

    /exit
  6. 킷 도구용 패키지 설치 — setup\4_install_kit_packages.bat
    목표
    PDF 처리 라이브러리(pymupdf)와 화면 검사 도구(playwright + Chromium)를 설치합니다. 방법 B(터미널)의 도구들이 사용합니다. 방법 A(웹앱)만 쓸 계획이어도 해 두는 편이 안전합니다.
    할 일
    setup\4_install_kit_packages.bat 을 더블클릭하고 기다립니다. Chromium 내려받기 때문에 2~5분 걸립니다.
    확인
    [OK] All CLI packages installed: pymupdf, playwright, Chromium.
Press any key to continue . . .
    새 터미널에서 아래를 붙여넣고 Enter → ok 한 글자가 나오면 성공입니다. 
    python -c "import fitz, playwright; print('ok')"
    안 되면
    인터넷 연결을 확인하고 같은 파일을 한 번 더 실행합니다. python을 찾을 수 없다고 나오면 6장.
    수동으로 할 때 (터미널에 붙여넣기)

    1) 패키지 설치

    python -m pip install --upgrade pip pymupdf playwright

    2) Chromium 설치

    python -m playwright install chromium
  7. (선택) codex 설치 — setup\7_install_codex_optional.bat
    목표
    학습 보조 그림을 그림 파일(PNG)로 만들고 싶을 때만 필요합니다. OpenAI 계정이 필요합니다. 건너뛰어도 됩니다 — 그 경우 Claude가 직접 그리는 벡터 도식(SVG)으로 대체됩니다.
    할 일
    setup\7_install_codex_optional.bat 을 더블클릭하고, 브라우저가 열리면 OpenAI 계정으로 로그인합니다.
    확인
    [OK] codex installed: codex-cli x.y.z
Press any key to continue . . .
    안 되면
    그냥 건너뜁니다. 빌드할 때 SVG로 그려줘 라고 말하면 됩니다 (6장).
    수동으로 할 때 (터미널에 붙여넣기)

    1) 설치

    npm install -g @openai/codex

    2) 로그인

    codex login

준비 완료 체크리스트

새 터미널을 열고 아래 명령을 한 줄씩 붙여넣어 봅니다. 오른쪽 결과가 나오면 준비가 끝난 것입니다.

명령 (복사해서 붙여넣기)기대 출력
python --version
Python 3.12.x (3.10 이상이면 됨)
node --version
v22.x.x (또는 v20 이상)
claude --version
버전 번호 + (Claude Code)
python -c "import fitz, playwright; print('ok')"
ok
codex --version
(선택) 버전 번호. 안 깔았으면 “찾을 수 없음”이 정상
비용 안내 본인 Claude 구독으로 동작합니다. 별도의 API 키를 발급받거나 결제할 필요가 없습니다. 컴퓨터에 ANTHROPIC_API_KEY 환경변수가 설정돼 있으면 구독 대신 그 키로 추가 과금되니, 구독으로 쓰려면 지워 두세요 (6장).

macOS / Linux 에서 준비하기

setup 폴더의 .bat 파일은 Windows 전용입니다. Mac/Linux는 터미널(Mac: Spotlight에서 “터미널”)에 아래를 한 줄씩 붙여넣습니다.

1) Python + Node.js

macOS (Homebrew 설치돼 있을 때):

brew install python@3.12 node

Ubuntu / Debian:

sudo apt update && sudo apt install -y python3 python3-pip python3-venv nodejs npm

5만들어진 페이지 활용하기

완성 파일은 그냥 열어서 읽으면 되지만, 알아두면 좋은 기능이 몇 가지 있습니다.

기본 사용법

  • Translation 탭 — 문장에 마우스를 올리면 원문·번역이 함께 강조됩니다. 문장을 클릭하면 형광펜이 칠해지고, 파일을 다시 열어도 남아 있습니다.
  • 그림 확대 — 그림·표를 클릭하면 크게 확대됩니다. 마우스 휠로 확대·축소, 드래그로 이동, Esc 로 닫기.
  • 학습 가이드 — 그림 옆 작은 버튼을 누르면 오른쪽에서 “이 그림 어디부터 볼까 / 결정적 숫자 / 저자의 주장 / 체크포인트” 가이드가 열립니다.
  • 메모 — 오른쪽 위 「메모」 버튼으로 자유롭게 필기할 수 있고, 브라우저에 자동 저장됩니다. 닫을 때는 × 버튼, 메모 안에서 Esc, 또는 메모 바깥을 두 번 연속 클릭.
  • Paper Study 탭 — 내 답을 먼저 쓰면 「분석 비교하기」 버튼이 열리고, 근거 칩을 누르면 Translation 탭의 해당 문장으로 이동합니다.
메모 저장에 대해 메모·형광펜은 그 컴퓨터의 그 브라우저에 저장됩니다. 파일을 다른 PC로 옮기면 따라가지 않습니다. 중요한 내용은 페이지의 「내보내기」 기능으로 파일(papers\1. shortname\study\)에 저장해 두세요.

선택 기능 — 내 메모로 Q&A 만들기 / 답변 검토받기 (고급)

Paper Study 탭에서 내가 쓴 답변을 AI 분석과 비교해 피드백받거나(「검토 결과 파악하기」), 메모에 적어 둔 질문을 Q&A 카드로 만들 수 있습니다(메모 안 「Q&A 생성」). 브라우저는 AI를 직접 부를 수 없기 때문에, 연결 다리 프로그램을 먼저 켜 둬야 작동합니다.

cd "C:\Users\내이름\Desktop\paper-review-kit"

이 기능을 안 써도 페이지 열람·학습에는 아무 지장이 없습니다.
