Paper Review Kit 사용법

논문 PDF → 8탭 학습용 HTML 한 장 · 프로그래밍 지식 없이 따라 하는 안내서
프로그램 소개 처음 한 번 준비 방법 A · 웹앱 방법 B · Claude Code 결과물 활용 문제 해결

1프로그램 소개

논문 PDF 한 편을 넣으면, 공부용으로 만들어진 웹페이지 한 장(HTML)이 나옵니다.

이게 무슨 프로그램인가요

영어 논문을 읽을 때 필요한 것들 — 문장별 번역, 그림·표 해설, 논문 구조 분해, 배경지식, 수식 정리, 비판적 질문 — 을 탭 8개짜리 학습 페이지 하나로 정리해 줍니다.

버튼 하나 누르면 끝나는 자동 변환기가 아닙니다. AI(Claude)와 채팅으로 대화하면서 단계별로 만들어 나가는 방식입니다. 그래서 중간에 이 번역 어색해 이 그림 다시 같은 요청을 넣어 고칠 수 있습니다.

결과물의 장점 그림·표가 파일 안에 전부 들어간 단일 HTML 파일입니다. USB에 담거나 메일로 보내도, 인터넷이 없어도, 다른 컴퓨터에서 더블클릭만 하면 그대로 열립니다.

완성되는 8개 탭

탭내용
Translation영어 원문 ↔ 한국어 번역을 문장 단위로 나란히. 마우스를 올리면 짝이 되는 문장이 같이 강조되고, 그림·표에 해석과 초보자 해설이 붙습니다.
Paper Study비판적 읽기 워크북. AI 해설을 보기 전에 내 생각을 먼저 적고, 그다음 AI 분석과 비교합니다.
Paper Dissection연구 동기 · 핵심 관찰 · 차별점 · 방법 · 실험 검증 · 한계 + 논문 총정리 카드.
Background이 논문을 읽기 전에 알아야 할 배경지식 카드.
Mathematics핵심 수식 풀이.
Diagrams비판적 질문 + 이해를 돕는 도식.
Code알고리즘 시뮬레이터 (기본은 빈 껍데기 — 필요할 때만 따로 요청)
Q & A자가 점검 문답 (기본은 빈 껍데기 — 공부하다 남긴 메모로 채울 수 있음)

두 가지 사용 방법 — 하나만 고르면 됩니다

방법 A · 추천
🌐 웹앱으로 하기
파일 하나를 더블클릭하면 브라우저 화면이 뜹니다. PDF를 끌어다 놓고 채팅창에서 대화합니다. 검은 터미널 화면을 볼 일이 거의 없습니다.
방법 B
⌨️ Claude Code로 하기
터미널에서 claude를 실행해 직접 대화합니다. 조금 더 빠르고 세밀하게 조정할 수 있습니다. 명령어 몇 개를 복사·붙여넣기만 하면 됩니다.

두 방법 모두 결과물은 같습니다. 그리고 두 방법 모두 아래 「처음 한 번 준비」가 먼저 끝나 있어야 합니다.

2처음 한 번 준비

이 3가지는 컴퓨터에 한 번만 설치하면, 이후로는 다시 할 필요가 없습니다.

  1. Claude Code 설치 + 로그인  (필수 — 이 키트의 엔진)

    claude.com/claude-code 의 안내대로 설치합니다. 설치 후 터미널에 claude 를 한 번 입력하면 브라우저가 열리고, 본인 Claude 계정(Pro/Max 구독)으로 로그인합니다.

    설치가 됐는지 확인: 터미널에 claude --version → 버전 번호가 나오면 성공.

    비용 안내 본인 Claude 구독으로 동작합니다. 별도의 API 키를 발급받거나 결제할 필요가 없습니다. 오히려 컴퓨터에 ANTHROPIC_API_KEY 환경변수가 설정돼 있으면 구독 대신 그 키로 추가 과금되니, 구독으로 쓰려면 지워 두세요.
  2. Python 3.10 이상 설치  (필수 — PDF에서 글자·그림 뽑는 데 사용)

    python.org 에서 내려받아 설치합니다. 설치 화면 맨 아래 “Add Python to PATH” 체크박스를 꼭 켜세요. (이거 하나 빠뜨리면 나중에 인식이 안 됩니다.)

    확인: 터미널에 python --version → Python 3.1x.x 가 나오면 성공.

    추가 설치 불필요 PyMuPDF 같은 라이브러리는 프로그램이 알아서 깝니다. Python 본체만 있으면 됩니다.
  3. codex CLI  (선택 — 학습용 삽화 생성에만 사용)

    설명 그림을 그림파일(PNG)로 만들고 싶을 때만 필요합니다. 없어도 전혀 문제없습니다 — 그 경우 Claude가 직접 그리는 벡터 도식(SVG)으로 자동 대체됩니다.

  4. 키트 폴더 준비

    이 안내서가 들어 있는 paper-review-kit 폴더 자체가 작업 공간입니다. 압축을 풀었다면, 한글·공백이 적은 경로(예: C:\paper-review-kit)에 두면 사고가 적습니다.

    폴더 안에 rawpaper 폴더가 있습니다. 공부할 논문 PDF를 여기에 넣어 두세요.

3방법 A · 웹앱으로 하기 (비개발자 추천)

파일 하나를 더블클릭 → 브라우저에서 PDF 올리고 채팅. 이게 전부입니다.

  1. 실행 파일 더블클릭

    키트 폴더 안 webapp 폴더로 들어가서:

    • Windows — win_start.bat 를 더블클릭
    • Mac / Linux — 터미널에서 ./webapp/linux_start.sh (처음 한 번은 chmod +x webapp/linux_start.sh 필요)

    검은 창이 하나 뜨면서 글자가 올라갑니다. 정상입니다. 이 창을 닫지 마세요 — 닫으면 프로그램이 꺼집니다.

    첫 실행은 몇 분 걸립니다 필요한 부품을 자동으로 내려받아 설치하기 때문입니다. 두 번째부터는 몇 초면 켜집니다.
  2. 브라우저가 자동으로 열립니다

    주소는 http://127.0.0.1:8765 입니다. (자동으로 안 열리면 이 주소를 브라우저에 직접 붙여넣으세요.) 내 컴퓨터 안에서만 도는 화면이라, 인터넷에 아무것도 올라가지 않습니다.

    화면은 왼쪽이 채팅, 오른쪽이 작업 패널입니다.

    ① PDF 업로드
    논문 PDF를 끌어다 놓는 자리
    ② 학습 보조 이미지 생성 방식
    「codex 터미널 (PNG)」 또는 「Claude 자체 (SVG)」 선택. codex가 없으면 자동으로 SVG로 고정됨
    ③ 논문 목록
    지금까지 만든 논문들. 완성된 HTML을 여기서 클릭
    ④ 미리보기
    완성된 학습 페이지를 화면 안에서 바로 확인
  3. PDF를 ① 자리에 끌어다 놓기

    올리자마자 왼쪽 채팅 입력칸에 요청 문장이 자동으로 채워집니다. 그대로 두고 Enter 를 눌러 전송하면 됩니다. 직접 문장을 쓸 필요가 없습니다.

    특별한 요청이 있으면 그 문장 뒤에 한국어로 덧붙이세요. 예: 번역은 최대한 직역으로 해줘

  4. 기다리기 (논문 한 편에 보통 수십 분)

    채팅창에 진행 상황이 실시간으로 흐릅니다. 🔧 표시는 AI가 도구를 쓰고 있다는 뜻입니다.

    멈춘 것 같아 불안할 때는 「중지」 버튼 왼쪽의 초록 점 + 경과 시간을 보세요. 시간이 계속 흐르면 정상 작동 중입니다.

    속도를 높이고 싶다면 요청할 때 본문 번역과 분석은 서브에이전트로 나눠서 동시에 진행해줘 한 문장을 붙이면 여러 작업을 병렬로 처리해 훨씬 빨라집니다.
  5. 결과 확인

    완성되면 오른쪽 ③ 논문 목록에 결과 HTML이 나타납니다. 클릭하면 ④ 미리보기에서 바로 보이고, 새 탭으로 크게 열 수도 있습니다.

    실제 파일은 papers 폴더 안 1. 논문이름 같은 폴더에 들어 있습니다. 그 안의 ○○○_output.html 이 최종 결과물이며, 이 파일 하나만 복사해서 어디로든 옮길 수 있습니다.

  6. 마음에 안 드는 부분 고치기

    그대로 채팅으로 말하면 됩니다. 예시:

    • Figure 3 그림이 잘렸어. 다시 잘라줘
    • 2.1절 번역이 어색해. 자연스럽게 다시
    • Q&A 탭도 채워줘

    끝낼 때는 검은 창에서 Ctrl+C 를 누르거나 창을 닫습니다.

4방법 B · Claude Code(터미널)로 하기

터미널을 열고 → 권한을 정하고 → 문장 하나 붙여넣으면 시작됩니다. 외울 명령어는 없습니다.

  1. 키트 폴더에서 터미널 열기

    Windows에서 가장 쉬운 방법 — 탐색기로 paper-review-kit 폴더를 연 다음, 위쪽 주소 표시줄을 클릭하고 거기에 cmd 라고 친 뒤 Enter. 그 폴더 위치에서 검은 창이 바로 열립니다.

    (또는 폴더 빈 공간에서 마우스 오른쪽 클릭 → 「터미널에서 열기」. Mac은 폴더에서 오른쪽 클릭 → 「폴더에서 새로운 터미널 열기」.)

    중요 반드시 키트 폴더 안에서 열어야 합니다. 이 폴더에 있는 규칙 파일(CLAUDE.md)을 Claude가 자동으로 읽고 시작하기 때문입니다. 엉뚱한 위치에서 열면 규칙을 모르는 채로 작업합니다.
  2. Claude Code 실행 — 권한 모드를 정해서 열기

    기본 실행은 이렇게 합니다.

    claude

    이렇게 열면 파일을 만들거나 명령을 실행할 때마다 “해도 될까요?” 하고 매번 물어봅니다. 논문 한 편을 만드는 동안 수십 번 물어보기 때문에, 아래 중 하나를 골라 두면 편합니다.

    권한 부여 방법 3가지

    방법어떻게추천 상황
    ① 물어볼 때 “계속 허용” 선택 실행 중 허가 창이 뜨면 화살표 키로 “Yes, and don’t ask again”(다시 묻지 않기) 항목을 골라 Enter. 같은 종류의 작업은 이후 자동 승인됩니다. 처음 써 보는 경우. 무엇을 허용하는지 눈으로 보면서 진행
    ② 실행 중 모드 전환 대화 도중 Shift+Tab 을 누르면 권한 모드가 순서대로 바뀝니다. 파일 편집 자동 승인(accept edits) 모드로 두면 대부분의 확인 창이 사라집니다. 중간에 질문이 너무 잦다고 느껴질 때
    ③ 처음부터 자동 승인으로 열기 아래 명령으로 실행 
    claude --permission-mode acceptEdits
    		 이미 한두 번 해 봤고, 끊김 없이 돌리고 싶을 때 (권장)
    주의 — 이건 함부로 쓰지 마세요 claude --dangerously-skip-permissions 는 모든 확인 절차를 끕니다. AI가 파일 삭제를 포함해 무엇이든 확인 없이 실행할 수 있습니다. 이 키트에서는 필요하지 않으니, 위 ①~③ 만 쓰시길 권합니다.

    권한을 잘못 줬거나 되돌리고 싶으면, 대화창에 /permissions 라고 입력하면 현재 허용 목록을 보고 수정할 수 있습니다.

    처음 실행이면 로그인 화면이 먼저 뜹니다. 브라우저에서 본인 Claude 계정으로 로그인하면 이후로는 다시 묻지 않습니다.

  3. 시작 문장 붙여넣기

    아래 문장을 복사해서 그대로 붙여넣고, <논문 파일명> 부분만 실제 PDF 이름으로 바꾸세요. (PDF는 미리 rawpaper 폴더에 넣어 둡니다.)

    rawpaper 폴더의 <논문 파일명>을 보고, 기존 지침(CLAUDE.md·workflow.md·rules)에 따라
학습을 위한 v4 대시보드 8탭 HTML을 생성해줘 (_build.py 조립 → tools/restyle_dash_v4.py 변환).
학습 보조 이미지가 필요하다고 판단되면, 플러그인 없이 터미널에서 codex를 직접 실행하는
방식으로 ImageGen을 활용해 이미지를 생성해. 이미지 내부에는 논문 제목·헤더 같은 글자는
넣지 말고, 내용과 내용을 설명하는 그림(도식)만 나오게 해줘.

    codex를 설치하지 않았다면 마지막 부분을 이렇게 바꾸세요 → 학습 보조 이미지는 codex 없이 Claude가 직접 SVG 도식으로 그려줘

    붙여넣기 팁 터미널에서는 Ctrl+V 또는 마우스 오른쪽 클릭으로 붙여넣습니다. 여러 줄이 한 번에 들어가며, 마지막에 Enter 로 전송합니다.
  4. 진행 지켜보기

    Claude가 대략 이 순서로 알아서 진행합니다. 중간에 질문을 하면 한국어로 답해 주면 됩니다.

    1. PDF에서 본문 추출 + 그림·표 자동 잘라내기
    2. 섹션·문단·문장 단위로 구조 정리
    3. 문장 단위 한국어 번역
    4. 탭별 분석 내용 작성 (해부 · 배경 · 수식 · 질문 · Paper Study)
    5. HTML 한 장으로 조립 (그림 전부 파일 안에 삽입)
    6. 자동 검증

    중간에 멈추고 싶으면 Esc. 완전히 끄려면 Ctrl+C 두 번. 나중에 claude --continue 로 하던 대화를 이어서 할 수 있습니다.

  5. 결과 열어보기

    papers 폴더 안에 1. 논문이름 형태의 폴더가 생기고, 그 안 ○○○_output.html 이 최종 결과물입니다. 더블클릭하면 브라우저에서 열립니다.

    고치고 싶은 게 있으면 터미널로 돌아와 그냥 한국어로 말하면 됩니다 — Table 2가 잘렸어, 다시 잘라줘 3장 번역 다시 해줘

5만들어진 페이지 활용하기

완성 파일은 그냥 열어서 읽으면 되지만, 알아두면 좋은 기능이 몇 가지 있습니다.

기본 사용법

  • Translation 탭 — 문장에 마우스를 올리면 원문·번역이 함께 강조됩니다. 문장을 클릭하면 형광펜이 칠해지고, 파일을 다시 열어도 남아 있습니다.
  • 그림 확대 — 그림·표를 클릭하면 크게 확대됩니다. 마우스 휠로 확대·축소, 드래그로 이동, Esc 로 닫기.
  • 학습 가이드 — 그림 옆 작은 버튼을 누르면 오른쪽에서 “이 그림 어디부터 볼까 / 결정적 숫자 / 저자의 주장 / 체크포인트” 가이드가 열립니다.
  • 메모 — 오른쪽 위 「메모」 버튼으로 자유롭게 필기할 수 있고, 브라우저에 자동 저장됩니다.
메모 저장에 대해 메모·형광펜은 그 컴퓨터의 그 브라우저에 저장됩니다. 파일을 다른 PC로 옮기면 따라가지 않습니다. 중요한 내용은 페이지의 「내보내기」 기능으로 파일로 저장해 두세요.

선택 기능 — 내 메모로 Q&A 만들기 / 답변 검토받기 (고급)

Paper Study 탭에서 내가 쓴 답변을 AI 분석과 비교해 피드백받거나, 메모에 적어 둔 질문을 Q&A 카드로 만들 수 있습니다. 이 기능들은 브라우저가 AI를 직접 부를 수 없기 때문에, 연결 다리 프로그램을 먼저 켜 둬야 작동합니다.

터미널을 하나 더 열어서 키트 폴더에서 아래를 실행하고, 그 창을 켜 둔 채로 학습 페이지의 버튼을 누르면 됩니다.

python tools/qa_bridge.py

Windows에서 한 번만 해 두면 버튼이 이 프로그램을 자동으로 켜 주게 만들 수도 있습니다(관리자 권한 불필요):

python tools/qa_bridge_register.py

이 기능을 안 써도 페이지 열람·학습에는 아무 지장이 없습니다.

증상해결 방법
python 또는 claude 를 찾을 수 없다고 나옴 설치가 안 됐거나 PATH 등록이 안 된 경우입니다. Python은 재설치하면서 “Add Python to PATH” 체크, Claude Code는 설치 안내를 다시 확인하세요. 설치 후에는 터미널을 껐다 새로 열어야 인식됩니다.
“Claude 로그인 필요” 메시지 터미널에 claude 를 입력해 로그인한 뒤 다시 실행하세요.
“API 키가 설정됨” 경고 구독으로 쓰려면 ANTHROPIC_API_KEY 환경변수를 삭제하세요. 두면 구독 대신 그 키로 과금됩니다.
웹앱 실행 창이 순식간에 닫힘 Python이 없거나 버전이 낮은 경우가 대부분입니다. 터미널에서 python webapp/start.py 로 직접 실행하면 원인 메시지를 읽을 수 있습니다.
브라우저가 자동으로 안 열림 주소창에 http://127.0.0.1:8765 를 직접 입력하세요.
그림이 잘리거나 옆 단 글자가 섞여 들어감 Claude에게 figure 2 다시 잘라줘. autocrop 하고 --verify로 확인해줘 라고 요청하세요.
번역이 어색한 한자어로 나옴 CLAUDE.md의 “무리한 한국어 변환 금지” 정책대로 다시 다듬어줘 라고 알려 주세요.
다른 PC에서 열었더니 그림이 안 보임 그림이 파일에 삽입되지 않은 상태입니다. 모든 이미지를 base64로 인라인해줘 라고 요청해 다시 만드세요.
너무 오래 걸림 / 멈춘 것 같음 논문 한 편에 수십 분은 정상입니다. 웹앱은 「중지」 버튼 왼쪽 경과 시간이 흐르는지, CLI는 글자가 계속 올라오는지 확인하세요.
중간에 끊겼음 CLI는 claude --continue 로 이어서 진행할 수 있습니다. 웹앱은 같은 채팅창에 아까 하던 작업 이어서 해줘 라고 하면 됩니다.
이용 범위 안내 완성된 HTML에는 원 논문의 그림과 원문이 들어갑니다. 이는 원저작자의 저작권이며 개인 학습 목적으로만 사용하세요. 외부 재배포·상업적 이용은 삼가 주세요. 자세한 내용은 키트 폴더의 NOTICE.md 를 확인하세요.
